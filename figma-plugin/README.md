# Algo & DS — App Mockup (Figma plugin)

Генерирует все экраны приложения прямо в Figma — как настоящие слои (текст, auto-layout, векторные иконки), а не скриншот — и связывает их кликабельным прототипом (`on click` → переход на другой экран), используя цвета и копирайт из самого приложения.

## Установка

1. Открой **Figma Desktop** (веб-версия Figma не поддерживает импорт локальных плагинов для разработки).
2. Создай новый файл (или открой существующий, куда хочешь добавить макет).
3. Меню **Plugins → Development → Import plugin from manifest…**
4. Укажи файл `manifest.json` из этой папки (`figma-plugin/manifest.json`).
5. Запусти: **Plugins → Development → Algo & DS — App Mockup**.

Плагин отработает несколько секунд и сам закроется, оставив 9 фреймов на холсте (два ряда), сгруппированных и выделенных, плюс уведомление с числом экранов.

## Что внутри

Экраны (ширина 390px, под мобильный прототип):

1. **Вход** — Email/Пароль, кнопка «Войти», ссылка на регистрацию
2. **Регистрация** — чек-лист требований к паролю, капча-плейсхолдер
3. **Профиль** — аватар, CTA-карточка «Перейти к алгоритмам», форма
4. **Главная** — поиск, список категорий
5. **Категория: Сортировки** — список алгоритмов с метками сложности
6. **Тема: Теория** — таб-бар (Теория/Визуализация/Код/Компилятор)
7. **Тема: Визуализация** — бары сортировки, плеер
8. **Тема: Компилятор** — выбор языка, редактор кода, вывод
9. **Настройки** — тема, скорость анимации, язык кода по умолчанию

## Прототип (клики)

- Вход → Войти → Профиль; → Регистрация
- Регистрация → Зарегистрироваться → Профиль; → назад → Вход
- Профиль → CTA-карточка → Главная; → иконка выхода → Вход
- Главная → категория → Категория; → иконка профиля/настроек
- Категория → алгоритм → Тема (Теория); → назад → Главная
- Тема: табы переключают между Теория/Визуализация/Компилятор; → назад → Категория
- Настройки → назад → Главная

Включи **Presentation mode** (`Shift+E` в Figma) на экране «Вход», чтобы прогнать прототип вживую.

## Если что-то пойдёт не так

Скрипт написан без внешних зависимостей (чистый Figma Plugin API), запускать безопасно — он не делает сетевых запросов (`networkAccess: {"allowedDomains": ["none"]}` в manifest). Если Figma покажет ошибку при запуске — пришли текст ошибки, поправлю `code.js`.
